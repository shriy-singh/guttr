# Security policy

Please **do not disclose vulnerabilities publicly** in GitHub Issues or discussion comments, particularly when they concern participant responses, project access, private storage, or account privileges.

To report a vulnerability, contact the maintainer privately at the contact address published on the official [GUTTR website](https://guttr.lovable.app). Include a concise impact description and non-sensitive steps to reproduce, without attaching respondent data or access tokens.

This public GitHub repository contains community documentation, not the full production source. A public issue is appropriate for ordinary usability problems but not for security flaws.
