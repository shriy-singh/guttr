# GUTTR visual tour

This guide describes five screens shared by the project creator in October 2026. The screenshot images are **not yet embedded in this repository**. They are being held for a separate image-upload step; this document deliberately avoids broken image links.

## Homepage

The home page uses an editorial black-and-white wall of actual workshop drawings behind a centered paper-toned card. The GUTTR wordmark and two primary actions introduce the product: Build a survey and Open the Experiment Room.

## Studio

The Studio opens with an existing survey, a template and picture sidebar, question-type controls, a central comic canvas, and a response inspector. Controls include Undo, Redo, Save file, Preview, Try a sample survey, and Run a response.

## Experiment Room

The paper-first creation flow includes a capture modal with camera permission and a visual alignment grid. This is a guide for camera capture, **not automatic cropping**, as indicated in the screenshot.

## Asset Hub

The catalog invites reusable kit contributions and visibly describes three stages: Describe, Upload, Review. It includes search and category filters, artist credit on hover, and a contribution action.

## Help

A long illustrated help page explains Experiment Room, Studio, respondents, kit contribution, and common questions with step-by-step screenshots.

## How to use the tour

Visit the [live website](https://guttr.lovable.app) to inspect these experiences. For historical implementation caveats and permission rules, consult the current build specification and the [source handoff](source-handoff.md); screenshots alone do not confirm back-end completion.

## Image publishing note

Original screenshot files are available from the project owner. They should be committed to a permitted public `docs/images/` location only after the GitHub upload path is confirmed. Do not confuse screenshots of the UI with a license to redistribute workshop artwork visible within them.
