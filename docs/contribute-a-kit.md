# Contribute a comic kit to GUTTR

GUTTR welcomes original comic elements that help people create interactive visual surveys. You do **not** need to be a programmer.

## Useful contributions

- Characters with multiple expressions and consistent poses
- Speech and thought bubbles, panel frames, arrows, gestures, reaction marks
- Modular props, background scenes, textures, and weather elements
- Accessible response visualizations and generic comic-technique examples
- Improvements to image descriptions, reading order, and usability

Please submit reusable components rather than copyrighted character cutouts or existing comics copied from other creators.

## How to propose a kit

1. Start a [Kit contribution proposal](https://github.com/shriy-singh/guttr/issues/new?template=asset-contribution.md). Share a description, not copyrighted files you are not authorized to publish.
2. Provide **kit title, creator name or credit preference, sample preview, source and provenance, editable formats, proposed license, and permitted uses**.
3. Confirm that you own the rights or are authorized to license the material. Indicate whether redistribution, remixing, commercial survey use, and standalone download are allowed.
4. A maintainer reviews relevance, line quality, rights, attribution, and compatibility with the existing library.
5. Only after acceptance and a suitable agreement should the files be published in the Asset Hub. No proposal is automatically accepted or ingested.

The product's current contribution form may prepare a kit file for review rather than uploading to a live public review service.

## Intellectual property and artist rights

**You retain ownership of your original art.** Posting a suggestion or submitting a proposal alone does not transfer copyright or grant GUTTR an unrestricted license. Any eventual right to host, adapt, distribute, or sell a kit must be established separately and clearly.

An asset offered as a gift is **not automatically public domain**. Different kits may have different licenses. The code and artwork have separate rights rules.

**Do not upload** proprietary workshop drawings, participant data, third-party media without reuse permission, account credentials, or private research materials.

## Credit and provenance

Proposed metadata should include creator, source, license, version, required attribution, and permissions. Published surveys using a kit should preserve provenance in an appropriate form. Details of the public attribution UI are still under development.

## What the public repository is for

Use GitHub Issues for suggestions, sample kits, method feedback, accessibility issues, and contributions to public documentation. The underlying GUTTR application code is not being opened for public copying or modification through this repository.
