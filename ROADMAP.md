# Guttr: Exploratory roadmap

This is a **proposed sequence**, not a release promise.

## Phase 0: Align the proposal

- Confirm name, positioning, target users, and intended first use case.
- Review the current Lovable website and code, and document what already exists.
- Resolve the highest-risk [open decisions](docs/open-decisions.md).
- Create a rights-safe starter collection of visual components.

## Phase 1: Test a narrow creation path

- Prototype a minimal comic composition flow and respondent preview.
- Test basic question and answer handling.
- Evaluate whether paper-first capture and region annotation can be supported in the initial scope.
- Conduct small usability sessions with creators and respondents.

## Phase 2: Research-capable pilot

- Add the selected survey logic and response exports.
- Introduce explicit survey and asset version snapshots.
- Evaluate a limited set of multimodal inputs with consent and storage protections.
- Run an ethically reviewed pilot study where required.

## Phase 3: Collaborative platform, if validated

- Extend role-based collaboration and publishing.
- Add artist contribution and licensing workflows.
- Expand hosting and integration options.
- Scale the library and research archive.

## Criteria before expanding

Choose based on observable creator usability, data reliability, researcher needs, accessibility, ethical requirements, engineering cost, and artist participation rather than an assumed feature-complete parity target.
