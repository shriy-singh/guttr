# Community comic kits

This directory will host **rights-cleared** workshop comics that contributors choose to publish for noncommercial remixing. The original surveys are not uploaded here until creator permissions and privacy checks are complete.

## Proposed naming

- `P01.pdf`, `P02.pdf`, etc. for approved project documents.
- `R01`, `R02`, etc. as researcher identifiers, where roles have been confirmed.
- `A01`, `A02`, etc. as artist identifiers, where roles have been confirmed.

Names belong in [the credit register](../docs/community-credits.md), not the filenames. Never infer whether someone was the researcher or artist solely from the order of names in an archive filename.

## Reuse

Approved and individually marked kits will use the **CC BY-NC-SA 4.0** noncommercial remix policy only after every relevant rights holder agrees. See [the policy](../docs/remix-policy.md).
