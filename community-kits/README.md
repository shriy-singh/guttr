# Community comic kits

GUTTR's community library is intended to make workshop-created comic surveys available for learning and **noncommercial remixing**, subject to the relevant signed agreements and a per-file publication review.

## Neutral project identifiers

- Public filenames: `P01.pdf`, `P02.pdf`, and so on.
- No participant, researcher, or artist names in repository filenames, catalog entries, or metadata.
- Researcher and artist role IDs (`R01`, `A01`) may be kept in private administration records where necessary. The public repository does not need a name-to-ID register.
- Artist recognition and any attribution required by the agreed licensing terms will be handled through GUTTR's creator-credit experience, not a public GitHub names directory.

## Intended reuse

The project owner has confirmed that workshop participants signed agreements. The proposed public reuse policy is noncommercial remixing, based on CC BY-NC-SA 4.0 where the actual agreement permits it. We will confirm the wording of the signed forms before asserting that any particular file carries this license.

## Publication status

Four supplied archives contain 15 PDF entries, including repeated project titles. A separately supplied five-page design-sprint PDF duplicates one archive entry by title. These are being prepared with anonymous public filenames, but the contents and permissions require review before public upload.

**Note:** Renaming a PDF does not anonymize the personal names or identifying marks that may appear *inside* it. Such content must be inspected before release.

The app's proprietary implementation is not part of this collection.
